# Ranveer Singh - Personal Portfolio Website

A modern, responsive, and aesthetic personal portfolio website for **Ranveer Singh** (B.Tech Student at JECRC University, Jaipur).

## 🌟 Key Highlights

- **Hero Section**: Dynamic introduction, B.Tech student badges, JECRC University & Jaipur location tags, quick action CTA buttons.
- **About Me**: Professional student background narrative, key pillars, and interactive stats.
- **Education**: Detailed B.Tech degree at JECRC University, Jaipur with coursework highlights.
- **Skills**: Attractive interactive skill cards for HTML, CSS, JavaScript, Python, Artificial Intelligence, Generative AI, Web Development, and Digital Productivity.
- **Projects**: Featured project cards for Personal Portfolio Website, AI Website Project, and Student Productivity Project with modal previews.
- **Achievements**: Dynamic filterable milestones (Certifications, Hackathons, Courses, Awards) + "Add Achievement" interactive capability.
- **Contact & Editable Socials**: Direct email card (`girvarsingh774@gmail.com`), one-click copy email, and live editable LinkedIn & GitHub links.
- **Theme Switcher**: Dark Mode / Light Mode toggle with smooth aesthetic transitions.
- **Constellation Canvas Background**: Interactive particle effects.
- **Zero-Config Vercel Deployment**: Configured with `vercel.json`.

---

## 🚀 Running Locally

You can run the portfolio locally using Python's built-in HTTP server:

```bash
python -m http.server 3000
```

Then open your browser and navigate to:
```
http://localhost:3000
```

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub or upload the project folder.
2. Go to [Vercel Dashboard](https://vercel.com).
3. Click **"Add New Project"** -> Select this repository.
4. Framework Preset: **Other / Static HTML**
5. Click **"Deploy"**.

---

## ✏️ Editing LinkedIn & GitHub Links

Click any **"Edit Links"** button or the gear icon on the website to open the social link manager. Enter your LinkedIn and GitHub URLs, and they will be saved to `localStorage` and dynamically applied across all buttons and sections on the site!
